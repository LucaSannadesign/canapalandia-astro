## Clearance gate
Mercati iniziali: UE, UK, USA.
Classi prioritarie Nice:
- 25 — abbigliamento
- 16 — poster/stampe
- 18 — borse/tote

Checklist vincolante:
- [ ] WIPO Global Brand Database: frase esatta + varianti.
- [ ] EUIPO / TMview: frase esatta + varianti fonetiche/semantiche.
- [ ] USPTO: ricerca nelle classi prioritarie e classi coordinate rilevanti.
- [ ] UKIPO: keyword/phrase + varianti.
- [x] Font/licenze commerciali: OFL 1.1 confermata per i tre font candidati.
- [ ] Look & feel finale dopo la produzione dei master.

Nota tecnica: le interfacce ufficiali WIPO/USPTO/EUIPO/UKIPO sono dinamiche e in alcuni casi protette da captcha/login. Una ricerca web indicizzata negativa non viene considerata clearance formale.
